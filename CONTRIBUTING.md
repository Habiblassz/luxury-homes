# Contributing to Luxury Homes

We welcome contributions! Please follow these steps to ensure a smooth process.

## Branch Naming
- Features: `feat/short-description`
- Bug Fixes: `fix/short-description`
- Chores: `chore/short-description`

## Pull Request Process
1. Ensure `npm run test:coverage` passes and coverage remains above 50%.
2. Ensure `npm run lint` and `npx tsc --noEmit` pass with no errors.
3. Keep commits focused and isolated to a single logical change.
4. Request review from at least one maintainer.
